# 《Klingenwerk Hartmann》 독일어 비즈니스 회화 연속 대화문 기획서

**세대교체 · 프로젝트 단계형.** 졸링겐의 4대째 칼 제조사에서 서른세 살의 후계자가 아버지에게서 회사를 물려받는다. 해외 진출을 자신의 첫 프로젝트로 삼아 독일식 프로젝트 절차(현황 점검 → 타당성 조사 → 입찰·계약 → 위기 대응 → 확산)를 하나씩 밟아 가는 이야기.
독일어 학습용 비즈니스 연속 대화문 (회의록·합성어·어휘·문법·이메일 견본·문화 메모 + 한글 해석 포함).

## 2. 프랑스어판과의 차이

| | 프랑스어판 《Maison Delcourt》 | 독일어판 《Klingenwerk Hartmann》 |
|---|---|---|
| 주인공 | 직원(수출개발 매니저)이 대표를 설득 | **후계자 본인**이 회사를 물려받아 직접 추진 |
| 갈등 축 | 재무이사 vs 수출 담당 | **세대 갈등**: 아버지·형·늙은 마이스터·노사협의회 vs 후계자 |
| 부 구성 | 문제 인식 → 준비 → 계약 → 위기 → 도약 | **프로젝트 생애주기**: Übergabe → Machbarkeitsstudie → Ausschreibung → Krisenstab → Rollout |
| 화 형식 | 대부분 회의실 대화 | **매 화 다른 독일식 업무 형식** (회사 행사, 정기회의, 공장 투어, 노사협의회, 은행 상담, 박람회, 퇴근 후 맥주 등) |
| 장면 | 한 장소, 한 장면 | **한 화에 여러 장면**(Szene 1–5), 장면 제목 표시 |
| 화자 | 4–5명, 발화 비중 비슷 | 5–7명, **비중을 고르지 않게** (주인공 중심 + 단역) |
| 1화 | 월요일 아침 실적 회의 | **회장 75세 생일 겸 승계 발표 행사** |
| 문서 구성 | 대화 → 핵심 표현 → 어휘 → 문법 → 문화 → 해석 | **프로젝트 상황판** → 대화 → **회의록(Protokoll)** → **합성어 분해** → 어휘 → 문법 → **격식 이메일 견본** → 문화 → 해석 |

## 3. 세계관

**회사: Klingenwerk Hartmann GmbH (클링겐베르크 하르트만)**
- 1921년 증조할아버지 빌헬름이 부퍼강 변 수력 연마 공방(Schleifkotten)에서 창업. 빌헬름 → 아우구스트 → 하인리히 → 펠릭스로 이어지는 4대째 가족기업
- 본사·공장은 졸링겐-발트, 직원 약 300명, 연 매출 4,800만 유로(전년 대비 -3%), 수출 비중 12% (오스트리아·스위스·네덜란드)
- 제품: 식칼, 커트러리, 가위. 손 연마 마감(Handabzug)과 법으로 보호되는 'Solingen' 각인이 강점
- 위기: 포화된 내수, 유통 체인의 가격 압박, 온라인 저가 수입품, 철강·에너지 비용, 숙련 연마공 고령화
- **상징 소품:** 1921년부터 사장에서 사장으로 전해지는 사슴뿔 손잡이 주머니칼. 1화에서 펠릭스에게 건네지고 70화에서 다음 세대로 이어진다.

**주인공: Felix Hartmann (펠릭스 하르트만)**
- 33세, 하인리히의 차남. 뮌헨의 경영 컨설팅 회사에서 10년 근무
- 숫자와 프로세스에는 강하지만 현장 사람들의 신뢰는 아직 없음
- 성장 곡선: 외부에서 온 '컨설턴트' → 현장을 존중하는 경영자 → 다음 세대에 회사를 물려줄 수 있는 리더

## 6. 화별 구성 템플릿

**대화 흐름 (120턴, 장면 3–5개)**
- 장면마다 `Szene N – 장소, 시간` 제목을 붙인다 (턴 수 제외)
- 한 화 안에서 격식 장면(회의·협상)과 비격식 장면(복도·맥주·전화)을 섞어 Sie/du 전환을 보여 준다
- 마지막 장면은 다음 화의 '형식'으로 이어지는 약속·전화·편지로 끝낸다

**문서 구성 (각 화)**
1. 헤더 — 단계·형식 / 장소·시간 / 등장인물 / 비즈니스 주제 / 학습 포인트 / 분량·난이도
2. **프로젝트 상황판 (Projektstatus)** — 단계, 이번 화 형식, 마일스톤, 미결 사항 (독일어 + 한국어)
3. 대화문 120턴 — 번호 없이 `화자: 대사`, 장면 제목과 이탤릭 지문
4. **회의록 (Protokoll)** — 이번 화의 결정 사항을 TOP(안건)별 독일 회의록 문체로 정리하고 한국어 번역을 붙임
5. **합성어 (Komposita) 분해** — 10–15개
6. 주요 어휘·표현 — 20–25개, CEFR 레벨 태그
7. 문법 분석 — 6–7개, 대화 속 문장 인용
8. **격식 이메일 견본** — 이번 화와 이어지는 독일어 업무 이메일 + 번역 + 구조 메모
9. 비즈니스 문화 메모 — 3–4개
10. **한글 해석 (맨 마지막)** — 장면 제목 포함, 대화 순서대로 전부 수록. 끝에 다음 화 예고(Ausblick)
