# 《Hoekstra Rijwielen · Team Mangwon》 네덜란드어 비즈니스 회화 연속 대화문 기획서

서울 망원동 빵집 사장님이 올린 영상 한 편. 그 영상 속 낡은 전기 카고바이크가 프리슬란트의 3대째 자전거 회사를 뒤흔든다.
사장도 수출 매니저도 아닌 **동료 네 명의 팀**이 아래에서부터 해외 진출을 밀어붙이는 스케일업 앙상블 드라마.
네덜란드어 학습용 비즈니스 연속 대화문 (어휘·문법·회의 표현 분석 + 한글 해석 포함).

## 0. 프랑스어판과의 차이

| 항목 | 프랑스어판 《Maison Delcourt》 | 네덜란드어판 《Team Mangwon》 |
|---|---|---|
| 주인공 | 수출 매니저 1명의 성장담 | 동료 4명의 팀 앙상블 (매 화 중심인물이 바뀜) |
| 출발점 | 위에서 아래로: 실적 악화 → 경영진 회의 → 대표의 결단 | 아래에서 위로: 바이럴 영상 → 쏟아지는 해외 문의 → 팀이 경영진을 설득 |
| 부 구성 | 문제 인식 → 시장 선정 → 계약 → 위기 → 도약 | 제품 생애주기: 아이디어 → 시제품·파일럿 → 자금 조달 → 규모 확대 → 임팩트 |
| 화의 형식 | 대부분 회의실의 공식 회의·협상 | 매 화 다른 회의 형식: 보렐, 스탠드업, 브레인스토밍, 회고, 화상통화, 피치, 직원평의회, 현장 방문 |
| 의사결정 | 대표가 결정 | 폴더 모델: 합의할 때까지 협의, 직원평의회(OR) 참여 |
| 대화 구조 | 하나의 연속 장면 | 장면 제목(Scène 1, 2…)으로 나뉜 3~5개 장면 |
| 화자 구성 | 주인공 중심의 고정 비율 | 장면마다 발언 비중이 크게 달라짐 |
| 문서 구성 | 핵심 표현 → 어휘 → 문법 → 문화 → 해석 | **오늘의 미션(대화 전)** → 대화 → **직설↔완곡 화법** → 어휘 → 문법 → **회의 진행 도구 표현** → 문화 → 해석 |
| 마무리 장치 | 다음 화 예고 | 매 부 마지막 화(14·28·42·56·70화)가 팀 회고(retro), 마지막 화는 1화 보렐의 거울 장면 |

## 2. 세계관

**회사: Hoekstra Rijwielen (훅스트라 자전거)**
- 1958년 창립, 3대째 가족 경영 자전거 제조사. 본사·조립공장은 프리슬란트 헤이렌베인, 직원 약 350명
- 시티바이크가 주력이고, 2019년형 전기 카고바이크 **Vracht(브라흐트, '화물')**는 판매 부진으로 단종
- 배경: 사람보다 자전거가 많은 포화된 내수 시장, 코로나 특수 이후의 재고 과잉, 온라인 직판 브랜드의 가격 공세
- 계기: 네덜란드 주재원이 서울에 두고 간 중고 브라흐트로 망원동 빵집 사장님이 골목 언덕을 오르며 빵을 배달하는 영상이 조회수 400만을 넘긴다

## 5. 화별 구성 템플릿

**대화 흐름 (120턴)**: 3~5개 장면으로 나누고 장면마다 제목(Scène 1 — 시간, 장소)을 붙인다. 장면에 따라 중심 화자가 바뀌며, 한 장면은 반드시 그 화의 회의 형식을 보여 준다.

**문서 구성 (각 화)**
1. 헤더 — 장소·시간 / **회의 형식** / 등장인물 / 비즈니스 주제 / 학습 포인트 / 분량·난이도
2. **오늘의 미션** (대화 전) — 상황, 팀이 결정해야 할 것, 귀 기울일 표현 3개
3. 대화문 120턴 — 장면 제목 + `화자: 대사`, 번호 없음
4. **직설 화법 ↔ 완곡 화법** — 대화 속 직설 표현과 완곡한 버전 6~8쌍
5. 어휘 — 25개 안팎, CEFR 레벨 태그
6. 문법 — 6개 안팎, 대화 속 문장 인용
