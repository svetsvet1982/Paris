# 《Le Cercle du Marque-Page》

파리의 프랑스 소설 독서 모임에서 만난 30대 남녀(엘리즈·앙투안)가 1년에 걸쳐 연인이 되어 가는 프랑스어 연속 대화문.

- 4부(가을·겨울·봄·여름) × 15화 = **60화**, 1화 = **정확히 100턴**(번호 1~100)
- 화마다 소설 구절 1개 인용 → 대화 속에서 낭독·재해석 → 끝에 **구절 번역 · 해설 · 사용 맥락 분석 · 표현 노트**(한국어)
- 설정·연표·화별 줄거리·인용문 목록: [`BIBLE.md`](BIBLE.md)
- 파일: `partie1/p1e01.md` … `partie4/p4e15.md`
- 검증: `python3 verify.py` (턴 1~100, 해설 섹션 확인)
