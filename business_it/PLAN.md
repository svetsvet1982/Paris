# 《Pelletteria Corsini》 이탈리아어 비즈니스 회화 연속 대화문 기획서

**가족 드라마 · 패션 캘린더형.** 명품 브랜드 하청에 기대 온 토스카나 스칸디치의 3대째 가죽 공방. 아버지가 떠난 뒤 서로 다른 미래를 꿈꾸는 삼남매가, 식탁과 공방과 해외 쇼룸을 오가며 '우리 이름을 단 가방'을 세상에 내놓기까지의 1년.
이탈리아어 학습용 비즈니스 연속 대화문 (감정·설득 표현, Lei↔tu 분석, 어휘·문법, 한글 해석 포함).

## 2. 세계관

**Pelletteria Corsini (펠레테리아 코르시니)**
- 1958년 우고 코르시니가 피렌체 근교 스칸디치에 세운 가죽 공방. 직원 약 250명, 연 매출 4,200만 유로
- 매출의 70%는 파리 명품 브랜드 **Maison Varenne(가상)** 위탁 생산(conto terzi), 30%는 자체 브랜드 **'Corsini 1958'** (토스카나 매장 12곳)
- 1화의 사건: 메종 바렌이 봄·여름 주문 40% 삭감 + 단가 5% 인하를 통보

## 6. 화별 문서 구성

1. 헤더 — 장소·시간 / **이번 화 시점** / 등장인물 / 비즈니스 주제 / 학습 포인트 / 분량·난이도
2. **가계도·인물 관계** — 대화문 앞에 배치 (이번 화에 등장하는 관계 중심)
3. 대화문 120턴 — 장면 제목(`Scena 1 — …`)으로 구분, 번호 없음
4. **감정·설득 표현** — 기능 / 표현 / 뜻 / 대화 속 예문
5. **Lei ↔ tu 전환 포인트** — 이번 화에서 존댓말·반말이 바뀌는 지점과 이유
6. **어휘 (주제별)** — 가족·식탁 / 생산·가죽 / 사업·숫자 / 감정·갈등 등으로 묶고 CEFR 태그
7. 문법 — 5~6개, 대화 속 문장 인용
8. **제스처와 구어 표현** — 감탄사, 말버릇, 몸짓, 지역 말씨
9. 비즈니스 문화 메모
10. **한글 해석 (맨 마지막)** + 다음 화 예고

## 7. 프랑스어판과의 차이

| 항목 | 프랑스어판 《Maison Delcourt》 | 이탈리아어판 《Pelletteria Corsini》 |
|---|---|---|
| 서사 유형 | 한 직원의 성장기 (실무자 → 리더) | 가족 앙상블 드라마, 화마다 시점 교체 |
| 부 구성 | 위기 → 준비 → 계약 → 시련 → 도약 | 패션 캘린더: 1월 피티 → 2~3월 밀라노 → 봄 아시아 → 여름 위기 → 성탄 승계 |
| 주 무대 | 회의실, 협상 테이블 | 일요일 식탁, 공방, 박람회, 해외 쇼룸 |
| 1화 | 월요일 아침 실적 회의 | 일요일 가족 점심에서 터진 주문 삭감 소식 + 밤의 빈 공방 |
| 화 내부 구조 | 한 장면, 도입·전개·절정·마무리 | 2~4개 장면, 비즈니스 장면과 가족 장면 교차 |
| 화자 분포 | 주인공 중심 | 6명 안팎이 불균등하게 겹쳐 말함 |
| 분석 섹션 | 핵심 표현·어휘·문법·문화 | 가계도, 감정·설득 표현, Lei↔tu 전환, 주제별 어휘, 문법, 제스처·구어, 문화 |
| 언어적 초점 | 회의·협상의 격식 표현 | 감정의 높낮이와 존댓말 전환, 구어와 서면 경어의 대비 |
